# Jane Guo — Academic Homepage

A minimal, framework-free academic homepage built with plain HTML and CSS.

## Preview locally

```bash
python3 -m http.server 3000
```

Then open `http://localhost:3000/`.

## Publish

The site is ready for any static host, including GitHub Pages, Cloudflare Pages,
Netlify, or a standard web server. The entry point is `index.html`.
